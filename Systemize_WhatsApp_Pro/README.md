# 🚀 Systemize — WhatsApp Pro Bulk Sender & Smart Scheduler
### تطبيق إرسال رسائل الواتساب الاحترافي المستقل وجدولة الحملات

---

## 🌟 نظرة عامة | Overview
برنامج **Systemize WhatsApp Pro** هو أداة سطح مكتب مستقلة فائقة التطور لإرسال رسائل واتساب جماعية وحملات تسويقية وتنبيهات مع جدولة ذكية، وتحكم كامل في التصنيفات والملفات المرفقة، مع نافذة مصغرة عائمة أصلية (Pure PySide6 Native Mini HUD Overlay) مثبتة دائماً في الزاوية العلوية اليسرى للشاشة لمتابعة الإرسال دون الحاجة لفتح المتصفح أو أي واجهة ويب.

## ⚡ الميزات الرئيسية | Key Features

### 1. 📁 استيراد جهات الاتصال وإدارة التصنيفات
- **دعم ملفات متعددة:** Excel (`.xlsx`, `.xls`) و `CSV` و **Google Contacts CSV** المصدرة من حسابات جوجل.
- **التعرف الذكي التلقائي على الأعمدة:** يتعرف تلقائياً على اسم العميل، رقم الهاتف، التصنيف، الملاحظات باللغتين العربية والإنجليزية.
- **تصحيح وترميز الأرقام المصرية والدولية:** تحويل الأرقام التلقائي إلى صيغة الواتساب الدولية (`2010...`، `2011...`، `2012...`، `2015...`).
- **فلترة سريعة بالتصنيف:** إمكانية فرز جهات الاتصال (مثل: VIP، أعضاء نشطين، عملاء محتملين Leads، اشتراك منتهي) والإرسال لتصنيف محدد أو للجميع بضغطة زر.
- **تحديد / إلغاء تحديد الكل:** اختيار جهات اتصال معينة أو استثناء أرقام محددة.

### 2. ✍️ صياغة الرسائل والمرفقات
- **قوالب مخصصة وديناميكية:** تخصيص الرسالة لكل عميل باستخدام متغيرات:
  - `{الاسم}` أو `{Name}`: اسم المستلم.
  - `{الهاتف}` أو `{Phone}`: رقم الهاتف.
  - `{التصنيف}` أو `{Category}`: فئة العميل.
  - `{ملاحظات}` أو `{Notes}`: أي ملاحظات مسجلة للعميل.
  - `{الوقت}` و `{التاريخ}`: الطابع الزمني الحالي.
- **دعم المرفقات:** إرسال صور (`.png`, `.jpg`, `.jpeg`, `.webp`) أو مستندات وملفات (`.pdf`, `.docx`, `.xlsx`).
- **معاينة حية للرسالة:** رؤية شكل الرسالة الحقيقي قبل البدء.

### 3. 🛡️ محاكاة السلوك البشري لحماية الرقم من الحظر (Anti-Ban)
- **حركة ماوس منحنية طبيعية (Bézier Curves):** حركة مؤشر الماوس غير خطية مع اهتزازات طبيعية تحاكي اليد البشرية تماماً.
- **سرعة كتابة متغيرة:** كتابة الحروف بتوقيت عشوائي يحاكي الكتابة اليدوية، أو لصق فوري ذكي مع تأخيرات طبيعية.
- **فترات انتظار عشوائية (Randomized Jitter):** فترات فاصلة بين كل رسالة وأخرى (مثلاً بين 10 و 20 ثانية مع ±3 ثواني عشوائية) لتفادي كشف خوارزميات السبام.
- **فترة راحة دورية (Cool-down):** أخذ استراحة لعدة دقائق تلقائياً بعد كل دفعة (مثلاً راحة دقيقة بعد كل 15 رسالة).

### 4. 🖥️ نافذة المتابعة المصغرة العائمة (PySide6 Native Top-Left Mini HUD)
- **نافذة أصلية خفيفة بدون أي ويب (Zero Web / Pure Windows Widget):** مبنية بالكامل باستخدام PySide6 مع خصائص `Qt.WindowStaysOnTopHint` و `HWND_TOPMOST` من Windows API.
- **ثابتة دائماً في الركن الأيسر العلوي (Top-Left):** تضمن عدم اختفائها حتى أثناء ظهور شاشة الواتساب أو البرامج الأخرى.
- **عرض لحظي للإحصائيات:**
  - شريط تقدم ملون.
  - عدد الرسائل المتبقية والناجحة والفاشلة.
  - اسم وهاتف العميل الحالي.
  - عداد تنازلي للرسالة القادمة.
- **أزرار تحكم سريعة:** إيقاف مؤقت (Pause)، استئناف (Resume)، إيقاف كلي (Stop)، واستعادة النافذة الرئيسية (Restore).

### 5. 🛑 زر الطوارئ الفوري (Physical Kill Switch)
- **مفتاح فوري عالمي:** بالضغط على `Ctrl + K` يتم إيقاف الإرسال في جزء من الثانية من خلال Windows Low-Level API (`GetAsyncKeyState`) حتى لو كان تطبيق الواتساب أو أي برنامج آخر في الواجهة ومحدد بالماوس.
- **قابل للتخصيص:** يمكن تغيير اختصار الطوارئ من تبويب الإعدادات ومحاكاة الماوس.

### 6. ⏰ الجدولة التلقائية الذكية (Auto-Schedule)
- إرسال فوري أو جدولة الإرسال لتاريخ وساعة محددة بدقة.
- عداد تنازلي حي حتى موعد بدء الحملة، مع تشغيل التنبيه والبدء التلقائي.

### 7. 📊 السجل والتقارير والتصدير (History & Reports)
- تقرير حي بالعمليات (الوقت، المستلم، الحالة، التفاصيل).
- إمكانية تصدير تقرير الإرسال والنتائج إلى ملف Excel بضغطة زر.

## 🚀 طريقة التشغيل | How to Run

### الطريقة الأولى (الأسهل بضغطة زر):
- انقر نقراً مزدوجاً فوق ملف **`RUN_WHATSAPP_SENDER.bat`**.
- سيكتشف المشغل تلقائياً بيئة بايثون المجهزة ويبدأ التطبيق فوراً.

### الطريقة الثانية (من موجه الأوامر Terminal):
```bash
python main.py
```

إذا كنت تستخدم بيئة بايثون جديدة، ثبت المتطلبات أولاً:
```bash
pip install -r requirements.txt
```

## 📋 دليل الاستخدام السريع | Quick Guide

1. **تشغيل تطبيق WhatsApp Desktop:**
   - تأكد من فتح برنامج **WhatsApp Desktop** الرسمي على الويندوز وتسجيل الدخول بحسابك.
2. **استيراد جهات الاتصال:**
   - من تبويب **جهات الاتصال والتصنيفات**، اضغط على **استيراد ملف (Excel / CSV / Google)**.
   - اختر ملفك (أو جرب الملفات الموجودة في مجلد `sample_data`).
3. **تصفية الفئات:**
   - يمكنك تحديد فئة محددة من القائمة المنسدلة (مثل VIP فقط) وتحديد الأرقام المراد مراسلتها.
4. **كتابة الرسالة والمرفق:**
   - انتقل لتبويب **صياغة الرسالة والمرفقات**.
   - اكتب نص الرسالة مع إدراج المتغيرات مثل `{الاسم}` بالضغط على أزرار الإدراج السريع.
   - اضغط **اختيار ملف مرفق** إذا كنت تريد إرسال صورة أو PDF.
5. **ضبط التوقيت والأمان:**
   - راجع إعدادات التأخير بين الرسائل (الموصى به: 10 إلى 20 ثانية).
6. **بدء الإرسال:**
   - انتقل لتبويب **بدء الإرسال والجدولة**.
   - اختر **إرسال فوري الآن** أو حدد موعداً مستقبلياً ثم اضغط **بدء حملة الإرسال**.
   - ستظهر فوراً **النافذة المصغرة العائمة** في أعلى يسار الشاشة لتتابع التقدم مباشرة مع إمكانية الإيقاف المؤقت أو الإلغاء.
   - **في حال حدوث أي خطأ:** اضغط مفتاح `Ctrl + K` فوراً للإيقاف الفوري التام.
