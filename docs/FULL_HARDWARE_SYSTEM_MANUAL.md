## 1. نظرة عامة والفرق بين النسختين (System Editions Comparison)

تم بناء نسختين مستقلتين تماماً لتلبية كافة الاحتياجات التشغيلية للصالة:

| الخاصية | النسخة الأولى (`web/`) | النسخة الثانية الشاملة (`web_full/`) |
|---|---|---|
| **نوع النظام** | Zero-Hardware Web Edition | Enterprise Full Hardware Edition |
| **الاعتماد على الأجهزة** | 100% مستقل بدون أي هاردوير | متكامل مع بوابات البصمة ESP32 وطابعات الـ POS |
| **تسجيل الحضور** | يدوي سريع بضغطة زر (HTMX Quick Check-in) | بيومتري آلي بالبصمة + تسجيل يدوي سريع |
| **بوابات البصمة (ESP32)** | غير مفعلة (معزولة) | **مفعلة بالكامل:** فحص اتصال، مزامنة، تسجيل بصمة R307، وحذف |
| **جهات اتصال Google** | غير مفعلة | **مفعلة بالكامل:** مزامنة آلية وفورية عبر People API |
| **طباعة الإيصالات** | طباعة متصفح قياسية A4 | **مزدوج:** قياسي A4 + إيصال حراري مخصص لطابعات الـ POS (80mm/58mm) |
| **المهام الخلفية المستمرة** | عند الطلب | **خادم أتمتة دائم (Daemon Worker)** لفحص البوابات وطابور الواتساب |
| **نظام رواتب المدربين** | مفعل بالكامل بنفس القواعد الرياضية | مفعل بالكامل بنفس القواعد الرياضية |
| **ملف التشغيل** | `start_gym_system.bat` | `start_gym_system_full.bat` |

## 2. موديول بوابات الدخول وأجهزة البصمة البيومترية (`apps/hardware`)

### أ. معمارية ربط جهاز ESP32 وحساس R307
يعتمد النظام على بروتوكول HTTP عالي الكفاءة يتواصل مباشرة مع فيرموير الـ ESP32 الأصلي عبر الشبكة المحلية:
- **`GET /status`**: التحقق اللحظي من اتصال البوابة، وحالة حساس البصمة البيومتري، وعدد الأعضاء المحملين في ذاكرة الجهاز.
- **`POST /members`**: مزامنة قاعدة بيانات التصاريح المشفرة بصيغة:
  ```json
  {
    "members": {
      "MEM-00001": {"fingerprint_id": 1, "allowed": true},
      "MEM-00002": {"fingerprint_id": 2, "allowed": false}
    }
  }
  ```
  *(تراعي المعمارية الخصوصية والأمان: لا يتم إرسال أي أسماء أو أرقام هواتف أو مبالغ مالية إلى جهاز البوابة)*.
- **`POST /enroll`**: بدء عملية التقاط البصمة على حساس R307 لمدة 90 ثانية، واستقبال معرف البصمة الجديد وحفظه في سجل العضو.
- **`DELETE /fingerprint`**: حذف قالب البصمة البيومتري من ذاكرة الحساس عند رغبة الإدارة.
- **`GET /last_scan`**: قراءة آخر عملية مسح بصمة، ومطابقتها مع العضو، وتسجيل الحضور آلياً، وإرسال بيانات العضو لشاشة الـ LCD الخاصة بالجهاز عبر `POST /display_member`.

### ب. وضع المحاكاة الافتراضية (Simulation Mode)
إذا لم يكن جهاز الـ ESP32 متصلاً بالكهرباء أو كان النظام قيد الاختبار، يمكن بنقرة واحدة من صفحة الإعدادات تفعيل **"وضع المحاكاة الافتراضية"**؛ حيث يقوم النظام بمحاكاة استجابات البوابة بدقة واختبار فتح الباب وتسجيل الحضور دون الحاجة للجهاز الفعلي.

## 3. موديول مزامنة جهات اتصال Google Contacts (`apps/integrations`)

- يتيح ربط حساب Google الخاص بالصالة لمزامنة أسماء وأرقام هواتف الأعضاء تلقائياً عبر **Google People API v1**.
- الفائدة التشغيلية: تظهر أسماء الأعضاء المسجلين مباشرة في تطبيق WhatsApp على هواتف إدارة الصالة بدلاً من ظهور أرقام مجهولة.
- إمكانية المزامنة الفردية بضغطة زر من صفحة العضو، أو المزامنة الجماعية الشاملة بضغطة زر واحدة.
- عزل كامل للأخطاء: في حال انقطاع الإنترنت أو انتهاء صلاحية المفتاح، يسجل النظام خطأ المزامنة دون التأثير على إيصالات الدفع أو عمليات الصالة.

## 4. إيصالات الـ POS الحرارية (Thermal POS 80mm / 58mm)

- تم تصميم واجهة طباعة إيصالات حرارية مخصصة لطابعات الـ POS المتصلة عبر USB أو الشبكة المحلية:
- مسار الوصول: `http://localhost:8000/payments/<ID>/thermal/`
- تنسيق ضيق متوافق مع ورق 80 مم و 58 مم، خط أحادي المسافة (Monospace) عالي الوضوح، فواصل مقطوعة، بدون أي أشرطة متصفح أو رؤوس صفحات زائدة.

## 5. خادم الأتمتة والمهام الخلفية الدائم (Automation Daemon)

يعمل خادم الأتمتة المستمر في نافذة خلفية عبر تشغيل:
[`start_automations_worker.bat`](file:///d:/move/career/gym%20system/start_automations_worker.bat)

يقوم هذا الخادم بتنفيذ المهام التالية دورياً:
1. **فحص بوابات البصمة دورياً (كل 5 ثوانٍ):** استطلاع البصمات الممسوحة، وتسجيل الحضور اللحظي في قاعدة البيانات، وعرض رسائل الترحيب وحالة الاشتراك على شاشات البوابات.
2. **معالج طابور الواتساب:** إرسال الرسائل المعلقة تلقائياً بمعدلات إرسال آمنة لمنع الحظر.
3. **تنبيهات الانتهاء اليومية:** عند حلول الموعد المحدد في الإعدادات (مثلاً `17:09`)، يقوم الخادم آلياً بفحص الاشتراكات المنتهية اليوم وتوليد رسائل التنبيه في طابور الواتساب.

## 6. كيفية تشغيل النسخة الكاملة (Enterprise)

1. **تشغيل الخادم الرئيسي الشامل:**
   - النقر المزدوج على: [`start_gym_system_full.bat`](file:///d:/move/career/gym%20system/start_gym_system_full.bat)
   - الرابط المحلي: `http://localhost:8000/`
   - رابط الهواتف والتابلت عبر الشبكة: `http://192.168.0.101:8000/`

2. **تشغيل خادم الأتمتة ومراقبة البوابات (اختياري / مستحسن مع الهاردوير):**
   - النقر المزدوج على: [`start_automations_worker.bat`](file:///d:/move/career/gym%20system/start_automations_worker.bat)

3. **بيانات الدخول:**
   - **المدير:** `manager` / `1234`
   - **الاستقبال:** `assistant` / `1234`

4. **نتائج الاختبارات الآلية للنسخة الكاملة:**
   - تم تشغيل 21 اختباراً آلياً شاملاً (`Ran 21 tests in 51.140s - OK`) تغطي كافة سيناريوهات الرواتب، والبوابات البيومترية، وتكامل Google Contacts.
